# Source media

Profile media is copied from the portfolio repository (`yeegz.github.io`, 14 October 2026), taken from the largest variant the portfolio publishes. `build_profile.py` embeds each image at twice the size it is drawn at, so these files are the ceiling, not what visitors download.

- `yousof-portrait.webp`: the hero portrait from `images/photos/yousof-portrait.jpg`, cropped to 4:5 (560 × 700).
- `bupples-{profile,accent,settings}.webp`: current app screenshots, `images/projects/bupples/current-*.webp`, 600px wide.
- `adelante-{widgets,today,discover}.webp`: current App Store captures, `images/projects/adelante/store-*.webp`, 600px wide.
- `photoshoot-landing.webp`: the red photobooth landing page, `images/projects/photoshoot/landing-2026-10.webp`, 1200px wide.
- `wayclub-workspace.webp`: the guided club workspace demo with fictional sample data, `images/projects/wayclub/club-workspace.webp`, 1200px wide.
- `codeatlas-workspace.webp`: the evidence workspace on a fixture repository, `images/projects/codeatlas/workspace.webp`, 1200px wide.

The older `photoshoot-artwork.webp`, `wayclub-workspace.png` and `fallenasteri.webp` are retained for historical artwork; they are not used by the current generator.
